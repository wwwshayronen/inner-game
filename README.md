# Inner Game

Cross-platform poker mental-performance app.

## Build installation files

Run **Actions → Build Inner Game mobile apps → Run workflow**.

The workflow produces:
- `InnerGame-v1.5-Android.apk`
- `InnerGame-v1.5-iOS.ipa` (after Apple signing secrets are configured)

The current source bundle is `InnerGame-v1.5-source.zip`.
